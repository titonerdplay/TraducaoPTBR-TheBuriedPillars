# TraducaoPTBR-TheBuriedPillars

Passo 1: Baixe o BepInEx 5.4.x para Windows x64 no link oficial.

Passo 2: Extraia o BepInEx na raiz do jogo (onde fica o .exe).

Passo 3: Execute o jogo uma vez e feche, para o BepInEx criar as pastas.

Passo 4: Baixe a pasta TraducaoPTBR deste repositório.

Passo 5: Copie a pasta TraducaoPTBR para dentro de BepInEx/plugins/.

Passo 6: Abra o jogo. A tradução estará ativa.
